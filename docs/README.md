# Les documents du projet, et à quoi chacun sert

Quatorze fichiers, quatre usages. Ce sommaire évite d'ouvrir le mauvais.

## Écrire des exercices

| Fichier | Quand l'ouvrir |
|---|---|
| [`pedagogie-agents.md`](pedagogie-agents.md) | **La règle du jeu.** Référentiel officiel d'abord, interdiction d'inventer, verbes de consigne, CORE/BONUS, vocabulaire destiné aux élèves. Chargé automatiquement à chaque session. |
| [`base-documentaire.md`](base-documentaire.md) | Où sont rangés les référentiels et les cours dans `cours-source/`, et comment en extraire le texte. |
| [`pedagogie-mapping-format.md`](pedagogie-mapping-format.md) | Le format d'une fiche de traçabilité : quels champs, quels états de validation. |
